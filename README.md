# BatteryWidget v2.1.0

An upgraded version of BatteryWidget, featuring a cleaner design inspired by the Mond Rainmeter theme.

### Improvements
- Made it efficient and lighter by removing icons.
- Redesigned vector battery indicator.
- Dynamic battery fill based on the current charge percentage.
- Dynamic color changes when the laptop is charging.
- Battery percentage displayed inside the icon.
- Estimated remaining battery time displayed below the indicator.
- Improved spacing and minimalist styling.

### Installation
1. Download `BatteryWidget-v2.1.0.zip`.
2. Extract the folder into your Rainmeter Skins directory.
3. Open Rainmeter and refresh the skin.
4. Configure the widget as needed.
